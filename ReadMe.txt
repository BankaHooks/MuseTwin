This project – is better way to find similar music as you already like. Not for genre, but a style, sound and a lot of different ways what you like in current song.
--------------------------------------------------------------------------------------------------------------------------------

Nowadays a lot of services can`t normaly find a music with same "vibe" as you listen some moments ago. This services often search only with same genre, not with same "vibe". Anyway I don`t like how this services works, so I`m trying to make another service.

Stack by the moment: 
1)ML-core: Python, Scikit-learn, Pandas, NumPy
2)Deploy: Git, 
3)Backend: FastAPI
